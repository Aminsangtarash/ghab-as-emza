# قبل از امضا

پلتفرم مشاوره و خدمات حقوقی با اولویت **امنیت** و **کیفیت**. صفحه اصلی مطابق طرح فارسی RTL پیاده شده است و مسیر اصلی کاربر — درخواست مشاوره آنلاین با کد پیگیری — روی Route Handlerهای Next.js کار می‌کند.

## استک پیشنهادی (و دلیل انتخاب)

برای این پروژه ترکیب زیر انتخاب شده است:

| لایه | انتخاب |
| --- | --- |
| فرانت | Next.js (App Router) + TypeScript + Tailwind + shadcn/ui |
| بک‌اند | همان Next.js با Route Handlers (`app/api/...`) |
| دیتابیس بعدی | MySQL (با Prisma) |

### چرا Next.js هم فرانت و هم بک‌اند؟

Route Handlerهای Next.js همان Node.js هستند؛ فقط در همان origin و همان ریپو اجرا می‌شوند. برای سایتی که خودتان با Next کار می‌کنید این یعنی:

- سطح حمله کوچک‌تر: بدون CORS بین دو سرور، کوکی `httpOnly` روی همان دامنه
- SEO بهتر برای مقالات و صفحات خدمات (SSR/SSG)
- یک استقرار، یک مدل احراز هویت، یک لایه اعتبارسنجی
- جدا کردن بک‌اند Express/Nest فقط وقتی لازم است که API مستقل برای اپ موبایل یا تیم بک‌اند جدا داشته باشید

### چرا MySQL نه SQL Server؟

- روی هاست‌های ایران در دسترس‌تر و کم‌هزینه‌تر است
- با Prisma و Next.js مسیر رسمی و مستند دارد
- SQL Server معمولاً وقتی معنا دارد که زیرساخت مایکروسافت از قبل در سازمان باشد (لایسنس، Active Directory، تیم DBA)

جدا کردن Node.js + SQL Server برای نسخه اول پیچیدگی عملیاتی اضافه می‌کند بدون اینکه امنیت را لزوماً بهتر کند. امنیت از اعتبارسنجی ورودی، حداقل داده، محدودیت نرخ، هدرهای HTTP، و بعداً رمزنگاری در حالت سکون و احراز هویت درست می‌آید؛ نه از جدا بودن فرآیند Node.

وقتی ورود/پرونده/اسناد واقعی اضافه شد: Prisma + MySQL، احراز هویت با کوکی امن، و ذخیره‌سازی اسناد خارج از دیتابیس (object storage) روی همین معماری سوار می‌شود.

## مسیرهای اصلی

- `/` صفحه اصلی
- `/services` و `/services/[slug]` خدمات
- `/consult` درخواست مشاوره آنلاین
- `/articles` مقالات
- `/lawyers` وکلا و متخصصان
- `/about` و `/contact`
- `POST /api/consultations` ثبت مشاوره (با اعتبارسنجی Zod و محدودیت نرخ)
- `GET /api/services` فهرست عمومی خدمات

ورود و ثبت‌نام در این نسخه رابط کاربری دارند؛ اتصال پایگاه‌داده و نشست امن مرحله بعد است. برای دریافت خدمت از فرم مشاوره استفاده کنید.
